# modes/ — 검증된 모드 스냅샷 (자본재의 핵심)

영상 1개는 소비재지만, **그 영상을 만든 설정의 스냅샷은 자본재**다. 이 폴더가 채널의 해자다.

## 규칙

1. 파이프라인을 끝까지 통과해 발행된 영상마다, orchestrator가 `_template.yaml` 형식으로 모드를 저장한다.
2. 모드 생명주기: `candidate` (1회 성공) → `validated` (3회 이상 재현) → `default` (신규 생산 기본값) → `retired`.
3. 발행 7일/30일 후 성과 데이터(`performance:`)를 추가하고, 개선 가설과 함께 모드를 업데이트한다 (개선 = 새 버전 파일 `-v2`, 원본 유지).
4. scriptwriter·video-producer는 작업 시작 전 적용 가능한 `default`/`validated` 모드를 먼저 찾는다. 모드가 있으면 모드 설정이 기본 골격보다 우선한다.

## 복리 공식

```
(검증된 모드 수 × 모드 품질) × (누적 라이브러리 × 에버그린 수명)
```

모드 없이 끝난 성공은 자본재로 남지 않는다 — 반드시 저장할 것.
