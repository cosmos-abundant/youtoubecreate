# 책 기반 대본 에이전트 (book-to-scripts)

주제정찰 파이프라인의 우회로. 입력 텍스트의 품질이 곧 산출 품질이므로 **사람이 엄선한 텍스트만** 받는다.

## 입력
- 양질 텍스트 파일 (학술서·고전·아티클 — 퍼블릭 도메인 또는 정당 인용 범위 확인 필수)
- `config/glossary.md` (용어집·금지규칙·준수규칙 — 번역 에이전트에서 검증된 자산 이식)

## 처리: 분할 프롬프트 방식 (번역 에이전트에서 검증된 패턴)

1. **분할**: 텍스트를 챕터(또는 의미 단위 ~5천자)로 분할.
2. **챕터별 처리**: 각 챕터에서 추출 — 단순 요약이 아니라:
   - **인사이트**: 통념을 뒤집는 지점, 의외의 인과
   - **재미요소**: 인간적 일화, 구체적 디테일, 극적 장면
   - **대본 씨앗**: "이것만으로 영상 1개가 되는가?" 후보 표시
3. **전체 요약**: 챕터 요약을 종합해 책 전체의 큰 그림 1페이지.
4. **선별**: 대본 씨앗들을 성공 주제·대본 공식으로 필터:
   - 에버그린인가? / 호기심 격차를 만들 수 있는가? / 시니어 회상 레이어와 연결되는가?
   - (가능하면) `library/topics/`의 검증된 주제 패턴과 대조
5. **배치 인계**: 선별된 씨앗을 scriptwriter 입력 형식으로 변환해 전달.

## 출력

`library/topics/book-<book-slug>/`:
```
summary.md          # 전체 요약 + 챕터별 요약
seeds.md            # 대본 씨앗 목록 (씨앗별: 핵심 인사이트, 재미요소, 추천 각도, 에버그린 판단)
queue/<seed>.md     # scriptwriter 인계용 — 주제 문서 형식 (출처는 해당 책 챕터로 태그)
```

## 규칙
- 원문 문장을 대본 씨앗에 복제하지 않는다. 사실·구조·인사이트만 추출.
- 씨앗마다 근거 챕터·페이지를 태그한다 (researcher의 [S] 태그와 동일한 역할).
- 한 책에서 씨앗 3개 미만이면 책 선정 자체를 재고하라고 보고한다.
