# Senior-Friendly — 시니어 친화 레이어 스킬

시니어는 '니치'가 아니라 **대본 스타일 레이어**다. 주제는 전 연령 에버그린 지식 그대로, 전달 방식만 시니어(고CPM·고시청지속 45~50%+)가 좋아하도록 설계한다. 전 연령 접근성을 해치는 순간 실패다.

## 5대 원칙

### 1. 천천히 · 또박또박
- 한 문장 = 1.5호흡 이내 (낭독 기준 약 25자 내외)
- 복문 금지에 가깝게: 관계절 중첩 시 문장을 쪼갠다
- TTS 설정: 속도 0.9~0.95배, 문장 간 휴지 0.4~0.6초 (video-producer 적용)
- 핵심 수치·인명 직전에 미세 휴지: "그 거리는, 38만 킬로미터였습니다"

### 2. 용어 즉시 풀이
- 전문용어는 등장 **즉시** 자연스러운 한 문장으로 풀이 (괄호 처리·각주 금지)
- 풀이 문구는 `config/glossary.md`에 고정 등록 → 영상 간 일관성
- 같은 영상에서 재등장 시 풀이 반복하지 않되, 10분 이상 지나 재등장하면 짧게 환기

### 3. 회상 · 향수 자극
- 역사·과거 사건은 시청자의 **세대 기억**과 연결: "교과서에서 배우셨던", "그 시절 라디오에서"
- 감각적 향수: 당시의 물가·풍경·일상 디테일을 1~2개 끼워넣는다
- 주의: 특정 세대만 아는 기준점에 영상 전체를 걸지 않는다 (전 연령 접근성)

### 4. 큰 그림 · 의미 부여
- 마무리는 반드시 "이 이야기가 오늘 우리에게 주는 의미"로 수렴
- 지식 전달로 끝나지 않고 삶의 통찰 1개로 닫는다 (설교 아닌 발견의 톤)

### 5. 존중하는 톤
- 가르치려 들지 않기: "~라는 사실, 모르셨죠?" 금지 → "기록을 함께 보시죠"
- 호들갑 금지: 과장 리액션·유행어·신조어·밈 배제
- 호칭은 "여러분", 시청자를 동행자로 대우 ("함께 따라가 봅니다")

## 비주얼·오디오 보정 (video-producer / thumbnail-meta)
- 자막·텍스트: 큰 글씨, 고대비, 화면당 1정보
- 썸네일 텍스트 3~5단어, 굵은 서체
- BGM은 내레이션을 침범하지 않게 (-18dB 내외), 급격한 효과음 자제

## 체크리스트 (script-critic 게이트 5)
- [ ] 1.5호흡 초과 문장 비율 < 10%
- [ ] 풀이 없는 전문용어 0건 (3건 이상 = 불합격 조건)
- [ ] 회상 연결 장치 1개 이상, 단 세대 한정 기준점에 과의존 없음
- [ ] 마무리에 큰 그림·의미 부여 존재
- [ ] 비존중 표현("모르셨죠?", 호들갑, 신조어) 0건
