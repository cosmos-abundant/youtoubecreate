# Made to Stick — SUCCESs 대본 적용 스킬

메시지가 기억에 남는 6가지 조건. 대본의 모든 블록은 최소 2개 원칙을 충족해야 한다.

## 의사결정 트리 (대본 작성 시)

```
이 블록의 핵심 메시지는 무엇인가?
├─ 한 문장으로 못 줄인다 → [Simple] 핵심 1개만 남기고 나머지는 다른 블록/영상으로
├─ 시청자가 이미 아는 얘기다 → [Unexpected] 통념을 먼저 세우고 깨뜨려라
├─ 추상적이다 ("매우 컸다") → [Concrete] 감각적 수치·비유로 ("여의도 3배")
├─ "정말?"이라는 의심이 든다 → [Credible] 소스 태그 명시 + 검증 가능한 디테일
├─ 머리로만 이해된다 → [Emotional] 통계를 한 사람의 이야기로
└─ 정보 나열이다 → [Story] 인물·갈등·해결의 서사로 재배열
```

## 대본 점수화 체크리스트 (script-critic 게이트 2)

각 항목 0~2점 (0=없음, 1=형식적, 2=효과적). 만점 12 → 10점 환산.

| 원칙 | 핵심 질문 | 2점 기준 |
|---|---|---|
| **S**imple | 영상 전체를 한 문장으로 말할 수 있나? | 핵심 명제 1개가 훅과 마무리에서 수미상관 |
| **U**nexpected | 통념을 깨는 순간이 있나? | "알고 보니 ~였다" 전환이 2회 이상, 훅에 1회 |
| **C**oncrete | 추상어가 감각으로 번역됐나? | 모든 큰 수치에 비유 병기, 장면 묘사 존재 |
| **C**redible | 믿을 근거가 대본 안에 있나? | 출처 언급 + 시청자가 스스로 확인 가능한 디테일 |
| **E**motional | 사람이 등장하나? | 통계 뒤의 개인 서사 1개 이상 |
| **S**tory | 갈등→해결 구조인가? | 블록 단위가 아니라 영상 전체가 하나의 서사 |

## 흔한 위반 (즉시 수정)

- **지식의 저주**: 작성자에게 당연한 배경을 생략 → 시니어 시청자 기준으로 모든 전제를 명시
- 의외성을 위한 과장 → 소스에 없는 과장은 Credible 위반, 사실 안에서 의외성을 찾을 것
- 디테일 과적 → Concrete는 "많은 디테일"이 아니라 "기억에 남는 1개의 디테일"
