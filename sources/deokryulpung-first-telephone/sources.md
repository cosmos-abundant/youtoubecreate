## 수집 환경 주의사항 (검증 한계 고지)

이번 시운전 환경에서는 웹페이지 직접 열람(WebFetch·curl)이 네트워크 정책으로 전면 차단되어,
**모든 사실은 웹 검색 결과 요약을 통해 수집**했다. 검색 요약은 출처 귀속이 합쳐질 수 있으므로:

- 귀속이 명확한 사실만 해당 [S##]에 단독 태그했다.
- 귀속이 불명확한 사실은 `(요약기반·귀속주의)`를 병기했다.
- **scriptwriter 단계 전, 핵심 수치·인용은 원문 페이지에서 재확인 권장** (특히 [S07][S08][S09]).
