# sources/ — 사실 리소스 풀

대본의 모든 주장이 인용되는 단일 원천. **여기에 없는 사실은 대본에 존재할 수 없다** (AI 슬롭 차단 규칙 1).

## 구조

```
sources/
├── _inbox/<video_id>/        # yt_subtitles.py 기본 출력 (주제 배정 전 임시)
├── books/<book-slug>/        # 책 기반 입력 (book-to-scripts)
│   └── source.md             # extract_docx.py 변환물 — 저작권상 git 미추적, 리서치 인풋 전용
│                             #   책 기반 출처 태그: [B-<book-slug>-NN]
└── <topic-slug>/
    ├── facts.md              # 사실 리소스 풀 — 모든 사실에 [S##] 출처 태그
    ├── sources.md            # [S##] 소스 대장: 제목, URL/서지, 라이선스, 수집일
    └── raw/                  # 자막 등 원시 자료 (리서치 인풋 전용 — 대본 직접 사용 금지)
```

## 소스 우선순위

1. 고전·학술·공공자료 (퍼블릭 도메인 / 기관 공개자료) — 저작권 최안전
2. 신뢰 가능한 기관·언론의 1차 출처
3. yt-dlp 자막 (구조·사실 참고만, 원문 복제 절대 금지)
4. 보유 서적 · NotebookLM 누적자료

## 품질 규칙

- 수치·연도·인명은 2개 이상 소스 교차 확인, 단일 소스는 `(단일출처)` 표기
- 상충 사실은 양쪽 기록 + 신뢰도 판단 병기
- 출처 태그 없는 문장이 facts.md에 있으면 researcher 산출물 불합격
