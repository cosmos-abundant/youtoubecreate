# 채널 리브랜딩 체크리스트 — 메타버스트렌드 → 역사산책

> 결정 사항 (2026-06-12): 채널명 **역사산책**, 기존 메타버스 영상 **전부 비공개 전환**.
> 브랜드 상세: `config/channel.yaml` (단일 기준 — Studio 입력값은 전부 여기서 복사)

## 1단계 — 백업 (비공개 전환 전, 필수)

- [ ] YouTube Studio → 콘텐츠에서 기존 영상 목록·조회수 캡처 또는 내보내기
- [ ] (선택) `yt-dlp --flat-playlist --dump-json <채널URL/videos> > library/_archive/metaverse-videos.jsonl` 로 메타 보존

## 2단계 — 기존 콘텐츠 정리

- [ ] Studio → 콘텐츠 → 전체 선택 → 공개 상태 → **비공개** (삭제 아님 — 복구 가능)
- [ ] 재생목록 전부 비공개 또는 삭제
- [ ] 채널 트레일러·추천 동영상 해제 (새 1호 영상 발행 후 재설정)

## 3단계 — 채널 정보 교체 (Studio → 맞춤설정 → 기본 정보)

- [ ] 채널 이름: `역사산책` ※ 이름 변경은 횟수 제한이 있으니(정책 기준 14일당 2회) 오타 없이 1회에 확정
- [ ] 핸들: `config/channel.yaml`의 후보 3개 중 선점 가능한 것 확정 → channel.yaml의 `url`/`handle` 갱신·커밋
- [ ] 채널 설명: channel.yaml `brand.description` 그대로 붙여넣기
- [ ] 설정 → 채널 → 기본 정보 → 키워드: channel.yaml `brand.keywords`
- [ ] 프로필 사진·배너: channel.yaml 콘셉트 참조 제작 (큰 글씨·고대비 — 시니어 가독성)

## 4단계 — 재출발

- [ ] 1호 영상: 덕률풍 (제작 인계문 `library/scripts/deokryulpung-first-telephone/handoff-production.md`)
- [ ] 발행 후 채널 트레일러로 지정
- [ ] 발행 완료 시 첫 모드 스냅샷 저장 (`modes/`) — 자본재 축적 시작

## 주의사항

- 이름을 바꿔도 구독자에게 별도 알림은 가지 않는다. 기존 구독자는 메타버스 관심층이므로 초기 노출 데이터(CTR·시청지속)가 실제 잠재력보다 낮게 나올 수 있다 → mode-improver 판단 시 이 편향을 감안할 것 (30일+ 데이터 기준 원칙).
- 채널 정체성 전환 후 알고리즘 재학습에 수개월이 걸릴 수 있다(성공률 3%·보상 7~10개월 전제와 일치). 단기 성과로 모드를 폐기하지 않는다.
- 기존 영상은 삭제하지 않았으므로, 만에 하나 되돌리고 싶으면 비공개 해제로 복구 가능.
