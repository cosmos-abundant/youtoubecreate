# 시작하기 — 다운로드부터 Claude Code로 진짜 콘텐츠 만들기 (우분투)

> 이 문서 하나만 따라 하면, 내 우분투 컴퓨터에서 Claude Code에게 **진짜 역사 영상 한 편**을 만들게 할 수 있습니다.
> 순서: ① 큰 그림 이해 → ② 다운로드 → ③ 환경 준비 → ④ 덕률풍으로 첫 영상(가장 빠름) → ⑤ 새 주제로 진짜 제작.

---

## 0. 큰 그림 (1분)

헷갈리기 쉬운 점부터 정리합니다.

- **GitHub은 "클라우드 보관함"일 뿐입니다.** 거기서 프로그램이 돌지 않습니다. 코드를 내 컴퓨터로 **받아서** 씁니다.
- 이 프로젝트는 **두 부분**으로 나뉩니다:
  1. **에이전트(대본·기획 AI)** → **Claude Code 안에서만** 작동합니다. (따로 실행하는 프로그램이 아니라, Claude Code에게 말로 시킵니다.)
  2. **파이썬 스크립트(영상 렌더)** → 내 우분투 **터미널**에서 실행합니다.
- 그래서 필요한 건 딱 둘: **Claude Code** + **우분투 터미널 환경(파이썬·ffmpeg)**.

## 1. Claude Code 준비

이미 Claude Code를 쓰고 계시면 건너뛰세요. 없다면 우분투 터미널에서:

```bash
# Node.js가 없다면 먼저 설치
sudo apt-get update && sudo apt-get install -y nodejs npm

# Claude Code 설치
npm install -g @anthropic-ai/claude-code

# 설치 확인
claude --version
```

> 설치 방법이 바뀔 수 있으니 막히면 공식 문서를 보세요: https://code.claude.com/docs
> 처음 실행하면 로그인(인증) 안내가 나옵니다. 그대로 따라가면 됩니다.

## 2. 저장소 다운로드 ⚠️ 브랜치 주의

**가장 중요한 함정**: 모든 작업물은 `main`이 아니라 **`claude/loving-galileo-3ib6m5`** 브랜치에 있습니다. 그냥 받으면 빈 폴더가 나올 수 있어요.

### 방법 A — git으로 받기 (권장)

```bash
git clone -b claude/loving-galileo-3ib6m5 https://github.com/cosmos-abundant/youtoubecreate.git
cd youtoubecreate
```

### 방법 B — ZIP으로 받기 (git이 낯설면)

1. https://github.com/cosmos-abundant/youtoubecreate 접속
2. 왼쪽 위 **브랜치 드롭다운**(보통 `main`)을 눌러 **`claude/loving-galileo-3ib6m5`** 선택
3. 초록색 **`Code`** 버튼 → **`Download ZIP`**
4. 압축을 풀고 터미널에서 그 폴더로 이동 (`cd ~/다운로드/youtoubecreate-...`)

## 3. 우분투 환경 준비 (복붙용 — 제가 검증한 명령)

```bash
# (1) 영상 합성 도구 + 한글 자막 폰트
sudo apt-get update
sudo apt-get install -y ffmpeg fonts-nanum

# (2) 파이썬 가상환경 (프로젝트 폴더 안에서)
python3 -m venv .venv
source .venv/bin/activate          # 켤 때마다 이 줄 실행 (터미널 새로 열면 다시)

# (3) 파이썬 패키지
pip install -r requirements.txt

# (4) 환경 점검 — 정상이면 "OK"와 함께 17개 통과
python3 -m unittest discover tests
```

마지막 줄에서 `Ran 17 tests ... OK`가 나오면 준비 끝입니다.

> **참고(제 테스트 환경)**: 위 명령은 제가 동일한 우분투 환경에서 직접 돌려 검증했습니다. `fonts-nanum`이 빠지면 영상 자막이 □□□로 깨지니 꼭 설치하세요.

## 4. 덕률풍으로 첫 영상 뽑기 (가장 빠른 성취 — 약 10분)

덕률풍 대본은 **이미 품질 검증(55/60)을 통과한 완성본**이 들어 있습니다. 그래서 대본 단계를 건너뛰고 바로 영상부터 만들 수 있어요. "이게 진짜 영상이 되는구나"를 먼저 눈으로 확인하는 단계입니다.

```bash
# (1) 씬 구성 미리보기 (어떤 장면들로 나뉘는지)
python3 scripts/produce_video.py library/scripts/deokryulpung-first-telephone/draft-v2.md --scenes-only

# (2) 진짜 렌더 — 한국어 음성(edge-tts) + 자막 + 화면 움직임
python3 scripts/produce_video.py library/scripts/deokryulpung-first-telephone/draft-v2.md

# (3) 썸네일
python3 scripts/make_thumbnail.py library/renders/ko/deokryulpung-first-telephone --text "큰절하고 받던 전화"
```

완성되면 여기에 파일이 생깁니다:
```
library/renders/ko/deokryulpung-first-telephone/
├── final.mp4        ← 완성 영상
└── thumbnail.png    ← 썸네일
```

> **(2)번에서 음성이 핵심 확인 지점입니다.** edge-tts는 인터넷에 연결해 한국어 음성을 받아옵니다.
> 제 작업 환경은 외부망이 막혀 있어 음성 대신 **무음으로 영상 골격(화면 움직임·자막·합성·한글폰트)까지만 검증**했습니다.
> 사용자님의 우분투(정상 인터넷)에서는 진짜 음성이 입혀집니다. 혹시 `edge-tts 결과가 비어 있음` 오류가 나면 인터넷/방화벽 문제이니, 우선 `--tts none`을 붙여 영상만 먼저 확인하세요:
> `python3 scripts/produce_video.py .../draft-v2.md --tts none`

## 5. 진짜 콘텐츠 제작 — Claude Code에게 새 주제 시키기

이제 본론입니다. 프로젝트 폴더 안에서 Claude Code를 켭니다:

```bash
claude
```

그리고 **새 주제 하나를 정해** 이렇게 말로 시키면 됩니다 (예시 그대로 복사해 주제만 바꾸세요):

```
역사산책 채널용으로 "거북선" 주제 영상을 만들어줘.
researcher로 사실 리소스 풀부터 만들고, scriptwriter로 대본을 쓴 다음,
script-critic 게이트(48/60)를 통과할 때까지 개선해줘.
대본 스타일은 다큐 정통(documentary), 길이는 롱폼(long)으로.
```

그러면 시스템이 알아서:
1. **researcher** — 웹에서 사실을 수집해 출처 태그를 단 `sources/<주제>/facts.md`를 만듭니다 (공개·학술·공공자료 기반, 저작권 가드레일 자동 적용).
2. **scriptwriter** — 그 사실에만 근거해 시니어 친화 대본을 씁니다 (무근거 생성 차단).
3. **script-critic** — 6개 항목으로 채점해 48/60을 넘을 때까지 고칩니다 (AI 슬롭·사실 오류 거름망).

대본이 통과하면 → 4번(영상)으로 갑니다.

### 대본 스타일·길이 바꾸기

주제 성격에 맞춰 골라 보세요 (자세히: `docs/script-modes.md`):

```bash
python3 scripts/script_mode.py --list      # 가능한 조합 보기
```
- 스타일: `documentary`(정통) · `mystery`(미스터리 추적형) · `first-person`(인물 1인칭) · `listicle`(N가지)
- 길이: `long`(8~10분) · `mid`(3~5분) · `short`(쇼츠 60초)

예: 쇼츠로 유입용 짧은 영상 → 지시에 "스타일 mystery, 길이 short로" 라고 말하면 됩니다.

### 통과한 대본으로 영상 만들기

대본이 `library/scripts/<주제>/draft-v2.md`(또는 최종본)로 통과하면, 4번과 똑같이 렌더합니다:

```bash
python3 scripts/produce_video.py library/scripts/<주제-slug>/draft-v2.md
python3 scripts/make_thumbnail.py library/renders/ko/<주제-slug> --text "후킹 문구"
```

> **영상 비주얼을 더 좋게**: 기본은 무료 텍스트 카드입니다. 실사 느낌을 원하면 무료 스톡 사진을 자동으로 넣을 수 있어요 (6번 참고). 더 나아가 AI 생성 이미지·영상도 붙일 수 있습니다(유료, `docs/video-production.md`).

## 6. 무료 / 키 필요 한눈에

| 하고 싶은 것 | 비용 | 필요한 것 |
|---|---|---|
| 대본 제작 (researcher·writer·critic) | 무료 | Claude Code |
| 텍스트 카드 영상 + 한국어 음성 + 자막 + 화면 움직임 | 무료 | ffmpeg, 인터넷(edge-tts) |
| 스톡 사진·영상 자동 삽입 | 무료 | `PEXELS_API_KEY` / `PIXABAY_API_KEY` (무료 발급) |
| AI 생성 이미지·영상 | 유료 | fal.ai 등 API 또는 MCP |
| 더 고급 한국어 음성 | 유료 | 슈퍼톤 / ElevenLabs API |

스톡 키는 발급 후 이렇게 등록합니다(터미널 세션마다, 또는 `~/.bashrc`에 추가):
```bash
export PEXELS_API_KEY="발급받은키"
export PIXABAY_API_KEY="발급받은키"
```

## 7. 막히면 (자주 나는 오류)

| 증상 | 원인·해결 |
|---|---|
| `ffmpeg: command not found` | `sudo apt-get install -y ffmpeg` 안 함 |
| 영상 자막이 □□□로 깨짐 | `sudo apt-get install -y fonts-nanum` 안 함 |
| `edge-tts 결과가 비어 있음` | 인터넷/방화벽 차단 → 우선 `--tts none`으로 영상만 확인 |
| `ModuleNotFoundError` | 가상환경 안 켬 → `source .venv/bin/activate` 후 `pip install -r requirements.txt` |
| clone했는데 폴더가 비었거나 파일이 적음 | 브랜치 문제 → 2번의 `-b claude/loving-galileo-3ib6m5` 확인 |
